# Ôn Anh

A place to strengthen your English vocabulary while you review and learn new grammar.
Nơi củng cố từ vựng và ôn ngữ pháp tiếng Anh.

One file, no build step: everything is in `index.html`.

## What is inside
- **Cover page** with floating stickers and a "word of the day".
- **Grammar**: Unit 1, present simple (learn, 8 warm-up questions, 50 practice questions).
- **Vocabulary**: your own word list, spaced review, adding words, and reading comprehension with six built-in texts.
- Every explanation is in English and Vietnamese.

## Put it online with GitHub Pages
1. On GitHub, create a new **public** repository, for example `on-anh`.
2. Click **Add file → Upload files**, drag in `index.html`, `README.md` and `.nojekyll`, then **Commit changes**.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick branch `main` and folder `/ (root)`, then **Save**.
4. After a minute or two the site is at `https://YOUR-USERNAME.github.io/on-anh/`.

To update later, upload a new `index.html` with the same name.

## How it behaves on GitHub Pages
- **Progress is saved in each person's own browser** (on that device only). Clearing the browser data, or using another device, starts from zero.
- **There is no login.** Anyone who has the link can open the site. Nothing personal is stored on a server, but the page itself is public.
- **Claude-powered buttons are off:** "Fill in for me" when adding a word, and "Make a new text with Claude" in Reading. The six built-in reading texts and everything else work.
- The page loads two Google Fonts (Fraunces and Be Vietnam Pro). Without internet it still works with plain fallback fonts.

## Tiếng Việt
- Đưa lên GitHub Pages: tạo kho **công khai**, tải `index.html`, `README.md`, `.nojekyll` lên, rồi vào **Settings → Pages** chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)`.
- Tiến độ học được lưu **ngay trên trình duyệt của từng người**, không lưu lên máy chủ. Đổi thiết bị hoặc xóa dữ liệu trình duyệt thì mất tiến độ.
- Trang **không có đăng nhập**: ai có liên kết đều mở được.
- Các nút dùng Claude (điền giúp từ mới, tạo bài đọc mới) sẽ bị tắt. Sáu bài đọc có sẵn và các phần còn lại vẫn dùng bình thường.
